## 🚀 Open Source

### 🧠 agent-dev-framework

A reusable framework for giving AI coding agents **structured and persistent project context**.

It helps preserve architecture decisions, coding standards, project knowledge, planning, and engineering workflows across AI coding sessions.

```bash
npx agent-dev-framework init
```
